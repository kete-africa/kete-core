# Technical decisions

One decision per file: `NNNN-short-title.md`, in the **MADR 4** format — start from
[`template.md`](template.md). Each records its status, date and deciders in its front matter, the
problem, the options considered, the outcome, its consequences, and what would reverse it. Entries
are never deleted; a new entry supersedes an old one.

Product and company decisions live in the doctrine repository (`kete-africa/kete`,
`docs/DECISIONS.md`).
