# The interface mockups

The mockups the author validates before a screen is built (doctrine D-057, D-061). Each version
starts from the previous file and only adds or moves: every entry of an older version still opens
in a newer one. The screens are in French, as Kete's users read them; the switcher at the bottom of
each page opens them.

| File | What it is |
| --- | --- |
| `canevas-v3.1.html` | The frame and the first places (validated 2026-10-13) |
| `simulation.html` | The whole system played end to end (validated 2026-10-16) |
| `canevas-v5.html` | « Pour moi », the thread with its state, the Kete thread, Planifier, Mon tableau, an agent, the phone |
| `canevas-v6.html` | What was decided on 2026-10-21: the decisions page, the thread at today's level, the agents, mail and imports, the phone |
| `canevas-v6.1.html` | v6, with the composer's two toggles, three gestures and « ⋯ », the narrow rail, the agents in the top bar, the Kete thread that hands work over |
| `canevas-v6.2.html` | **The reference** (D-061): v6.1 with cases A and B, an agent's computer, taking on work and « rendre à », no left border on any component |

Every screen is built and screenshot beside its mockup, on a computer and a phone, in light and dark.
