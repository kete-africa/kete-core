# Bien démarrer avec Kete

> **Projet.** Le guide d'une organisation qui découvre Kete, écrit d'après les écrans du 18 octobre 2026. Il sera publié sur kete.software avec la documentation.

## 1. Créer son compte et son organisation

1. Sur le **Compte Kete**, choisissez « Créer un compte » : votre nom, votre e-mail, un mot de passe.
2. Créez votre organisation : son nom. Vous en êtes la propriétaire.
3. Dans **Mon espace › Sécurité**, activez la seconde vérification, ou ajoutez une clé d'accès
   (passkey) pour vous connecter sans mot de passe.

Un seul compte ouvre toutes les applications Kete : vous ne vous inscrivez qu'une fois.

## 2. Mon espace : votre centre de réglages

| Page         | Ce que vous y faites                                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------------------------------------- |
| Mes outils   | Ouvrir Kete Enterprise et les applications de votre organisation                                                            |
| Mon Kete     | Déployer Kete Enterprise : partagé (prêt tout de suite), dédié, chez vous ou autonome ; sa région ; les applications à côté |
| Organisation | Inviter des collègues (lien valable sept jours), donner les rôles membre ou administrateur                                  |

| Sécurité     | Seconde vérification, clés d'accès, mot de passe                                                                            |

## 3. Kete Enterprise : le centre de l'organisation

À gauche, les lieux :

- **Pour moi** — ce qui a besoin de vous, le plus pressant d'abord : ce qui attend votre décision,
  ce que vous tenez, votre journée. « Clore ma journée » le soir.
- **Kete** — Kete Intelligence : demandez, confiez une tâche ; l'assistant lit, calcule, compare et
  **prépare** ; vous décidez de ce qui engage. Il est aussi à droite de chaque page (le bouton
  « Kete » en haut).
- **Fils** — chaque projet, chaque affaire a son fil ; les messages WhatsApp, Telegram et les e-mails
  y arrivent avec un responsable.
- **Déléguer** — vos agents : ce que vous leur confiez, ce qu'ils ont fait, ce qui attend.
- **Planifier** — la semaine de tous les outils : rendez-vous, échéances, congés, tâches.
- **Projets**, **Tiers**, **Mon tableau** — vos affaires, vos clients et fournisseurs, vos indicateurs.

En bas : les **Applications**, les **Réglages** (vos préférences ; ceux de l'organisation pour un
administrateur) et l'**Administration**.

## 4. Mettre l'organisation en place (administrateur)

Dans **Administration** :

1. **Structure** — les unités (filiales, sites, services), les postes, qui les tient.
2. **Personnes et comptes** — chaque personne et son compte Kete.
3. **Droits** — les rôles et ce qu'ils permettent, par unité.
4. **Modules** — ce que l'organisation utilise.
5. **Politiques** — les règles qui s'appliquent aux gestes, des personnes comme des agents.
6. **Boîtes mail**, **Connecteurs**, **Outils** — ce que Kete lit et utilise de vos outils actuels.

Les **Réglages** de l'organisation fixent la monnaie, les jours ouvrés, les jours fériés… pour toute
l'organisation ou pour une unité (une filiale au Ghana peut facturer en cedis).

## 5. Les agents : jusqu'où ils vont

- Un agent travaille **pour une personne, jamais au-delà de ses droits**.
- Ce qui engage est un **brouillon** que vous validez dans « À faire » ou dans la conversation.
- Dans **Réglages › Agents**, un administrateur choisit ce qu'ils font au-delà de Kete : chercher et
  lire sur le web, travailler sur un ordinateur à eux. Rien de cela n'est actif au départ.
- Dans **Administration › Outils**, il importe vos propres outils (une description OpenAPI, un
  serveur MCP) : un outil qui lit agit seul, un outil qui agit prépare un brouillon, un outil qui
  supprime demande une confirmation.
- Sous chaque réponse, « Écouter » la lit à voix haute ; dans vos Réglages, « Lire les réponses à
  voix haute » le fait à chaque réponse.
